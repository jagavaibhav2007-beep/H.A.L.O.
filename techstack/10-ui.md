# Tech Stack: UI / UX

Design: [systemdesign/10-ui](../systemdesign/10-ui.md). Global stack: [00-stack-summary](00-stack-summary.md).

## Feature-specific
| Concern | Choice | Notes |
|---|---|---|
| Shell | **Tauri** | light native windows, tray, always-on-top companion |
| Frontend | **React** | component ecosystem |
| Styling | CSS (custom) — glassmorphism, baby-blue/royal-blue, theme-aware | native CSS covers blur/gradients; add a utility/animation lib only if it earns its place |
| Window behavior | Tauri window APIs (floating, always-on-top, resize/expand) | companion → full workspace |
| State from Brain | WebSocket client → React state | UI holds no business logic |
| Live desktop stream | screenshot frames over WS (Lanes 2/3) | watch-it-drive view |
| List perf | virtualized activity log | smooth with long history |

## Cost note
- **Zero recurring cost** — pure local rendering. No cloud, no paid UI services.

## Build order
- Phase 1 deliverable: this shell with mocked Brain events, so the premium feel is real before the backend exists.
